# 내화채움구조 선형조인트 탐색기

2026-10-31 기준 인정현황과 PDF 57건을 제공하는 정적 웹사이트입니다.
공개 GitHub Pages로 게시하면 인터넷 이용자 누구나 자료를 볼 수 있습니다.

## 배포 준비

저장소 기본 브랜치에 이 폴더의 전체 내용을 올리고 Settings > Pages > Source에서 GitHub Actions를 선택합니다. 배포 완료 후 Pages의 Visit site를 확인합니다. `.github` 폴더와 그 내부 워크플로도 포함해야 합니다.

## 월간 점검의 범위

GitHub Actions는 매월 15일 한국시간 09:00 기준으로 연구원의 내화채움구조 전체 인정현황 목록과 PDF를 확인합니다. 실제 시작 시각은 GitHub 측에 의해 지연될 수 있습니다. 목록이 현재 웹사이트 기준 원본과 다르면 화면에 알립니다. 실행 실패는 Actions 실행 결과에서 확인할 수 있습니다.

**새로운 항목·인정변경·취소의 자동 추출, PDF 연결, 분류, 웹사이트 데이터 갱신은 아직 구현되어 있지 않습니다.** 최신 자료 차이를 감지하는 기능만 제공하며 이를 자동 갱신 완료로 보아서는 안 됩니다. 2026-10-31 이후의 개별 인정변경·취소 공고를 전수 확인한 것은 아닙니다.

GitHub 공개 저장소에서 60일간 저장소 활동이 없으면 예약 워크플로가 자동으로 비활성화될 수 있습니다. 사용하는 계정과 알림 설정으로 실행 결과를 관리해야 합니다.
