# 내화채움구조 선형조인트 탐색기 - 월간 갱신 저장소

한국건설기술연구원(KICT) 건축자재등[내화채움구조] 전체 인정현황 중 선형조인트 항목과 세부 인정내용 PDF를 매월 점검·수집하는 저장소입니다. 화면 공유는 사내 공유본(Claude 아티팩트)으로 하며, 이 저장소는 자료 갱신만 담당합니다.

## 구성

| 시각 (KST) | 주체 | 하는 일 |
|---|---|---|
| 매월 15일 10:17 | GitHub Actions (`.github/workflows/pages.yml`) | `scripts/update.py` 실행 → 연구원 인정현황·공고 확인 → `index.html`(DATA), `docs/`, `rows/`, `update-status.json` 갱신 후 커밋 |
| 매월 15일 오후 | Claude 예약 작업 | 이 저장소를 받아 사내 공유본에 변경분 반영 (띄어쓰기 보정 포함) |

GitHub 예약 실행은 GitHub 사정으로 늦어질 수 있습니다. Actions 탭의 "Monthly catalogue update"에서 "Run workflow"로 수동 실행할 수 있습니다.

## 자동 갱신 동작

- 연구원 전체 인정현황 PDF에서 선형조인트 행(FS-FF/FC/HW/WW)을 추출하고, 기준일 이후의 신규인정·인정변경·인정취소 공고에서 세부 PDF를 찾아 연결합니다.
- 세부 PDF를 하나로 확정하지 못한 신규 항목은 PDF 없이 "원문 대조 확인 필요"로 표시됩니다.
- 신규 항목의 커튼월 분류(외벽 형태·프레임·단열재)는 자동으로 채워지지 않아 수작업 검토가 필요합니다.
- 기존 인정번호가 원본에서 사라지거나 항목 수가 급감하면 갱신을 중단하고 기존 데이터를 유지합니다.

`update.py`는 `index.html`의 `const DATA=[...];let cat=` 구간과 `<div class="alert"><b>…</b>…</div>` 문구를 직접 바꿉니다. 이 두 패턴은 유지해야 합니다.

## 공개 범위

이 저장소가 공개 저장소이면 자료와 PDF는 누구나 내려받을 수 있습니다. 화면(GitHub Pages)은 배포하지 않으므로, 이전에 배포된 사이트는 Settings > Pages에서 게시 중단(Unpublish)해야 공개 화면이 사라집니다.
